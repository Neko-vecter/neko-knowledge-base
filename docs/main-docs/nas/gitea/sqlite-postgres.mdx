# Gitea sqlite 迁移到 postgres

## package require

- psql

### install package

```shell
sudo apt install postgresql-client
```

## 迁移流程

### dump database

在开始之前需要先给 gitea 数据库 dump 出 sql 文件

```shell
docker exec -it gitea /bin/bash

su git

gitea --config /data/gitea/conf/app.ini dump \
    --database postgres --skip-repository --skip-custom-dir \
    --skip-attachment-data --skip-package-data --skip-index \
    --file /tmp/gitea-dump.zip
```

复制到工作目录

```shell
docker cp gitea:/tmp/gitea-dump.zip ./
unzip gitea-dump.zip
```

### Deploy Postgres

使用 Docker 部署 Postgres

```yml title="docker-compose.yml"
networks:
  gitea:
    external: false

services:
  db:
    image: docker.io/library/postgres:18
    restart: always
    environment:
      - POSTGRES_USER=gitea
      - POSTGRES_PASSWORD=gitea_password
      - POSTGRES_DB=gitea
    networks:
      - gitea
    volumes:
      - ./pgdata:/var/lib/postgresql
    ports:
      - "5432:5432"
```

### migrate sqlite to postgres

使用以下命令连接上数据库

```shell
psql -h localhost -U gitea -d gitea  
```

使用以下命令导入 sql 到 postgres

```sql
\i gitea-db.sql
```

### 部署 Gitea (postgres)

在 Compose 文件中添加以下配置

```yml title="docker-compose.yml"
networks:
  gitea:
    external: false

services:
  server:
    container_name: gitea
    depends_on:
      - db
    image: docker.gitea.com/gitea:latest
    restart: always
    networks:
      - gitea
    volumes:
      - ./data:/data
      - /etc/timezone:/etc/timezone:ro
      - /etc/localtime:/etc/localtime:ro
    ports:
      - "3000:3000"
      - "2222:22"

    environment:
      - GITEA__database__DB_TYPE=postgres
      - GITEA__database__HOST=db:5432
      - GITEA__database__NAME=gitea
      - GITEA__database__USER=gitea
      - GITEA__database__PASSWD=gitea_password
```

### 更新 Gitea 数据库部分配置文件

```ini title="app.ini"
[database]
DB_TYPE = postgres
HOST = db:5432
NAME = gitea
USER = gitea
PASSWD = gitea_password
LOG_SQL = false
SCHEMA = 
SSL_MODE = disable
```
