# Meow Lint

Meow Lint 是一个自定义规则检查器。可以使用轻松添加 module 到检查器中。

:::info

[Neko-vecter/meow-lint](https://github.com/Neko-vecter/meow-lint)

:::

## cli 参数

```shell
python3 <path_to>/src/content_lint.py -i "<path_to>/file1.mdx" "<path_to>/file2.mdx"
```
